# Курсовая работа «Резервное копирование» / Dog Images Uploader to Yandex.Disk
**Учебный проект - Итоговая работа по модулю "ООП и работа с API"**  
  
**Автор:** Vlad Koretskii  
**GitHub:** [Профиль в Гихаб](https://github.com/VladKoretski)  

Данный проект позволяет загружать случайные изображения собак из публичного API [dog.ceo](https://dog.ceo) и сохранять их в папку на Яндекс.Диске с использованием REST API.

## Возможности
- Получение списка всех пород (breeds) и подпород (sub-breeds).
- Скачивание случайного изображения для выбранной породы (или для всех пород сразу).
- Автоматическое создание папки на Яндекс.Диске.
- Загрузка файлов с формированием имени вида `{порода}_{оригинальное_имя}.jpg`.
- Ведение JSON-отчёта о результатах загрузки (успех/ошибка) – `results.json`.
- **Логирование** всех важных событий и ошибок в файл `app.log` (с меткой времени, уровнем и именем модуля).
- Повторные попытки при временных сетевых сбоях и таймаутах (настраиваемое количество).

## Требования
- Python 3.8+
- Установленные зависимости (`requirements.txt`)
- Аккаунт Яндекс.Диска и OAuth-токен для доступа к API (`.env.example`)

## Использование
Запустите основной скрипт в среде разработке или через терминал:

```bash
python main.py
```

Необходимо будет выбрать режим:
- **1** – загрузка случайных изображений для **ВСЕХ** пород (по одному на породу и подпороду).
- **2** – загрузка изображений для **конкретной** породы (включая её подпороды).
При выборе режима 2 введите название породы на английском (например, `african`, `poodle`, `bulldog`).  
  
**После завершения работы:**  
* Все изображения будут сохранены в папку на Яндекс.Диске:
    - при режиме 1 – папка `AllBreeds`;
    - при режиме 2 – папка с именем породы с заглавной буквы (например, `Bulldog`).
* В корне проекта появится файл `results.json` с детальной информацией о каждой загрузке.
* В файл `app.log` будут записаны все логи работы программы (включая ошибки и предупреждения).

## Файл `results.json`

Пример содержания:

```json
[
  {
    "breed": "african",
    "original_url": "https://images.dog.ceo/breeds/african/n02116738_1049.jpg",
    "saved_name": "african_n02116738_1049.jpg",
    "status": "success"
  },
  {
    "breed": "wild",
    "original_url": "https://images.dog.ceo/breeds/african/wild/n02116738_1090.jpg",
    "saved_name": "wild_n02116738_1090.jpg",
    "status": "error"
  }
]
```

* `breed` – название породы или подпороды.
* `original_url` – исходная ссылка на изображение.
* `saved_name` – имя файла на Яндекс.Диске.
* `status` – `"success"` или `"error"` в зависимости от исхода загрузки.

## Логирование
Проект использует встроенный модуль `logging` для записи всех событий в файл **`app.log`**.
* **Уровень логирования** – `INFO` (можно изменить на `DEBUG` в функции `setup_logging()` в `main.py` для более детальной отладки).
* **Формат записи**:  
  `<время> - <имя_модуля> - <уровень> - <сообщение>`
* Логи сохраняются **только в файл**, не дублируются в консоль, чтобы не засорять пользовательский интерфейс.
* В лог попадают:
    - все запросы к API dog.ceo и Яндекс.Диску;
    - успешные и неудачные попытки загрузки;
    - ошибки соединения, таймауты, повторные попытки;
    - создание папок, сохранение отчёта.

## Настройка повторных попыток и таймаутов
В коде предусмотрены параметры для управления надёжностью:

* `timeout` – максимальное время ожидания ответа от сервера (сек).
* `retries` – количество повторных попыток при сбое.
* `delay` – задержка между попытками (сек).  
Эти параметры передаются при создании объектов `DogBreedsAPI` и `YandexDisk` в `main.py`. Вы можете изменить их под свои нужды.

## Примечания

* Для предотвращения перегрузки API между запросами вставлены задержки (0.2–1 секунда).
* При ошибках загрузки конкретного файла выполнение не прерывается – ошибка фиксируется в отчёте и логе, а загрузка продолжается.
* Все HTTP-запросы к dog.ceo и Яндекс.Диску защищены повторными попытками при таймаутах.
* Если папка на Яндекс.Диске уже существует, она не создаётся заново (ошибка 409 обрабатывается как успех).
